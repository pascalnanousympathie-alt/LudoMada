Terms of Service

Draft for operator review: publish only after the verified operator and applicable jurisdiction/contact have been filled in and the production deployment matches these terms.

Service

Mada Commander provides authenticated access to a user's own explicitly paired device and registered workspace. Supported operations include bounded text/source file reads and writes, fixed Git/npm/Gradle test/build tasks, and structured control of the paired Opera/noVNC browser. The public service is separate from any private self-hosted developer control plane.

Authorization

Connect only devices, repositories, and workspaces you own or are authorized to administer. Keep Google sign-in, pairing codes, and the local agent token private. Revoke lost or unused agents promptly.

Acceptable use

You may not attempt cross-account access, evade access controls, impersonate another user, or use the service to access another person's data. The public MCP does not support free-form shell commands, arbitrary absolute filesystem paths, raw CDP WebSocket control, arbitrary JavaScript, password/credential fields, or browser cookies. It does allow bounded project-relative source changes, fixed test/build jobs, navigation, and selected visible-control actions. These operations may change source files or browser settings; users must authorize the project/device, review edits, and verify results.

Availability and risk

This early service may be unavailable, return incomplete diagnostics, or change during development. Diagnostics are not a substitute for reviewing code, maintaining backups, or independently verifying a system before release. Do not use it for emergency, safety-critical, or regulated workflows.

Account termination and data

Use the account page to revoke an agent or request deletion of the Mada Commander public-service account. Test deletion against the deployed database and document backup/log retention before general publication.

Publisher/contact

The verified publisher must supply a legal/contact identity and jurisdiction before public launch.
