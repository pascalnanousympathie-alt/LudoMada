Privacy Policy

Before publication: this policy must be reviewed against the final production deployment, actual retention settings, and the selected hosting/identity providers. The operator must provide a monitored privacy contact.

Information processed

When deployed, Mada Commander may process the verified Google account subject and email, display name, a hashed web-session identifier, hashes of authorization and agent tokens, agent names and check-in times, project aliases and labels, branch names and short commit hashes, diagnostic job status and bounded diagnostic output, and security/rate-limit records. The exact live implementation and hosting configuration govern what is stored.

Local project data

The local agent stores its bearer token and the absolute paths you explicitly register in an owner-only local configuration file. Absolute paths are not sent in the agent heartbeat. The public service receives the project alias, display label, branch, short commit hash, and narrow results of supported diagnostics. Do not register a workspace unless you are authorized to administer it.

Purpose and access

Account data is used for authentication, one-user-per-agent authorization, diagnostics, abuse prevention, and support. A signed-in user must not be able to access another user's agent, projects, jobs, or tokens. The public MCP does not expose general-purpose shell execution or unrestricted file access.

Retention and providers

The operator must document the actual database/hosting provider, Google OAuth, log retention, job retention, data deletion flow, and any subprocessors before claiming production compliance. Expired credentials and one-time codes are rejected; the operator should run regular cleanup for expired records.

Your choices

You can stop your local agent, revoke its pairing from the account page, remove project registrations locally, and stop using the service. The dashboard includes a Delete my account action that removes Mada Commander service records and revokes the account's registered agents. This is not a promise about infrastructure backups; the verified operator must document backup/log retention and provide a monitored privacy contact before launch.

Security contact

Report suspected account-isolation or token-exposure issues through GitHub Security Advisories for LudoMada. Never attach tokens, pairing codes, cookies, or raw credentials.
