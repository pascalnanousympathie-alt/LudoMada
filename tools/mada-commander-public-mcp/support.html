Mada Commander Support

Mada Commander is an early-stage public diagnostic agent. If connection fails, first check the service status page and confirm the local agent is running.

Pairing issues

Pairing codes expire quickly and can be used once. Generate a new code after an error. Keep the local agent configuration file private; it contains an access token.

Diagnostics

The public service supports fixed read-only profiles only: Git status, toolchain versions, and basic inventory. It cannot execute arbitrary shell commands or browse/edit local files.

Security and privacy

Report suspected cross-account access, agent-token exposure, or unexpected data disclosure through GitHub Security Advisories. For ordinary bugs, use LudoMada Issues. Never include passwords, OAuth tokens, pairing codes, browser cookies, raw logs with secrets, or personal screenshots.

Account/device access

Sign in to the same account to view and revoke your own paired agents. If an agent is lost, revoke it and remove the local configuration file from the device you control.
