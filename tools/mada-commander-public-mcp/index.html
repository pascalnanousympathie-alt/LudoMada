2. Register a project locally

The local agent holds your project path. The cloud sees only your alias, label, branch and short commit hash.

node ~/LudoMada/tools/mada-commander-public-mcp/agent.mjs project-add ludomada LudoMada "$HOME/LudoMada"

Replace the alias, label and path for your own project. You must install/pair the local agent yourself.

3. Start the local agent

Keep the agent running while you want the MCP to access your registered project. It polls the service outbound and only accepts fixed diagnostic profiles.

node ~/LudoMada/tools/mada-commander-public-mcp/agent.mjs run

Stop it with Ctrl+C. Revoke it from this page whenever you no longer trust the device.

Account and privacy

You can sign out or permanently delete your Mada Commander public-service account. Account deletion revokes agents and removes the public-service account records and jobs; it does not delete the local project files on your device.

Public service boundary

  • Only projects registered on your local agent are visible to your account.
  • Public diagnostics are restricted to Git status, toolchain versions, and basic project inventory.
  • No arbitrary shell command, arbitrary file read/write, browser-session control, APK installation, or GitHub merge is exposed.
  • Access tokens are revocable; local agent tokens are kept in an owner-only configuration file.
Mada Commander is an early public-service implementation. Protected features remain unavailable until the operator completes the secure service setup. Review Privacy, Terms, and Support. Never send access tokens, pairing codes, or private logs to support.
